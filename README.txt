BIONIX YOGA LAB — лендинг v9 «Тишина» для загрузки на хостинг
================================================================

Состав архива
-------------
index.html   — страница сайта (маркер сборки: 9.0-tishina)
support.js   — движок страницы
vendor/      — библиотека React
fonts/       — шрифты Oswald и Manrope (полная кириллица, локально)
assets/      — фотографии: полная версия и -m для телефонов
.htaccess    — кэширование и сжатие
Сайт не обращается к внешним CDN и Google Fonts — открывается в России без VPN.

Как загрузить по FTP
--------------------
1. Подключитесь к хостингу FTP-клиентом (FileZilla, Cyberduck, Total Commander).
2. Откройте корень сайта (public_html, www или httpdocs).
3. Загрузите СОДЕРЖИМОЕ папки (index.html, .htaccess, support.js, vendor/, fonts/, assets/) прямо в корень,
   сохраняя структуру. На вопрос о замене — «Перезаписать всё». Тип передачи — «Двоичный».
4. Проверка: откройте сайт, Ctrl+U, найдите bionix-build — должно быть 9.0-tishina.

Перед запуском
--------------
- Почта для кнопки «Написать»: в index.html найдите  this.props.email || ''  и впишите адрес
  между кавычками, например  this.props.email || 'yoga@bionix.ru'
- Telegram (необязательно): аналогично  this.props.telegramUrl || ''  — пусто = ссылка скрыта.
- Форма заявки работает как демонстрация: данные никуда не отправляются. Подключите отправку
  в CRM, на почту или в Telegram-бот.
- Фото преподавателей и часть фото направлений/зон сгенерированы ИИ — заменить реальной съёмкой.
- Отзывы: блок убран до получения реальных отзывов с согласием авторов.
- Яндекс Метрика — подключить после согласия в cookie-баннере.
- Дата редакции и выделенные поля в документах 152-ФЗ.
