Состав архива
-------------
index.html   — страница сайта (маркер сборки: 10.0-tishina)
support.js   — движок страницы
vendor/      — библиотека React
fonts/       — шрифты Oswald и Manrope (полная кириллица, локально)
assets/      — фотографии: полная версия и -m для телефонов

Сайт не обращается к внешним CDN и Google Fonts — открывается в России без VPN.

Как загрузить по FTP
--------------------
1. Подключитесь к хостингу FTP-клиентом (FileZilla, Cyberduck, Total Commander).
2. Откройте корень сайта (public_html, www или httpdocs).
3. Загрузите СОДЕРЖИМОЕ папки (index.html, .htaccess, support.js, vendor/, fonts/, assets/) прямо в корень,
   сохраняя структуру. На вопрос о замене — «Перезаписать всё». Тип передачи — «Двоичный».
4. Проверка: откройте сайт, Ctrl+U, найдите bionix-build — должно быть 10.0-tishina.

Настройки в index.html
----------------------
- Почта для кнопки «Написать»: найдите  this.props.email || ''  и впишите адрес между кавычками,
  например  this.props.email || 'yoga@bionix.ru'
- Telegram (необязательно): аналогично  this.props.telegramUrl || ''  — пусто = ссылка скрыта.
- Баннер месяца: чтобы скрыть, замените  this.props.offerOn ?? true  на  this.props.offerOn ?? false
- Формулировки УТП: сейчас «Единственный…», «Самый большой…», «Только у нас…» — как в брифе.
  Нейтральный вариант без превосходной степени: замените  this.props.claims ?? 'Как в брифе'
  на  this.props.claims ?? 'Без превосходной степени'

Перед запуском
--------------
- УТП «единственный / самый большой / только у нас»: по закону о рекламе (38-ФЗ, ст. 5) такие
  утверждения нужно подтверждать документами. Без подтверждений включите нейтральный вариант.
- Форма заявки работает как демонстрация: данные никуда не отправляются. Подключите отправку
  в CRM, на почту или в Telegram-бот.
- Часть фото Пражской сгенерирована ИИ — заменить реальной съёмкой.
- Направления по клубам (таблицы «Направления йоги» и «Звуковой велнес») — подтвердить.
- Яндекс Метрика — подключить после согласия в cookie-баннере.
- Дата редакции и выделенные поля в документах 152-ФЗ.
